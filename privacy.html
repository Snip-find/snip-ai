This policy describes, at a high level, information that may be processed when you use Snip, a tool that helps locate relevant passages in webpages and PDFs. The final policy should be reviewed against the exact version of Snip you publish.

Information you provide

When you search, Snip processes the question you enter and the webpage text or PDF URL/content supplied for that search. The web API accepts a question and text blocks. The PDF search API accepts a question and a public PDF URL, downloads the PDF for text extraction, and analyzes extracted text. Do not submit confidential, highly sensitive, or personal information unless you have permission and have assessed whether using Snip is appropriate.

AI-assisted search

For webpage text search, Snip sends selected candidate passages and your question to the OpenAI API for relevance verification when the API is configured to do so. The PDF workflow extracts text and then uses the search API to analyze selected passages. AI-generated or AI-assisted results can be incomplete or incorrect; check the original source before relying on them. OpenAI's handling of submitted data is governed by its own terms and privacy documentation.

Technical processing

Snip's API processes requests to return relevant passages. The PDF endpoint retrieves the public PDF URL you provide, subject to size and URL restrictions, and extracts readable text. Hosting providers and service providers may process technical request data as part of operating their services. The exact logs, analytics, account data, and retention periods depend on the deployed configuration and must be confirmed before this policy is finalized.

Payments and subscriptions

If subscriptions are offered, payment details are handled through the payment provider used in the actual checkout flow. Snip should not claim a payment provider is active until the live checkout configuration is verified. Consult the provider's privacy policy for its processing of payment information.

Retention and security

We do not state a specific retention period or make a blanket deletion or security guarantee on this page because those details must be verified against the current infrastructure and provider settings. Access controls, logging, backups, and deletion procedures should be documented before this policy is treated as final.
