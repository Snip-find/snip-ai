Architecture note
- The popup sends `{question, url}` to `https://snip-chi.vercel.app/api/pdf-find`. That remote service selects evidence; the extension then uses bundled PDF.js to verify/highlight a matching phrase.
- The IndexedDB text index is used for local page-text reuse during anchoring, not as the semantic retrieval engine. The extension still requires the remote API for question understanding and passage selection.
